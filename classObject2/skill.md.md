# QT 实验报告AI自动评语生成工具 技能文档
## 一、项目背景
课程设计原基础任务多数同学借助AI和现成库快速完成，因此启用**B计划实战任务**。
基于Qt开发桌面客户端，批量读取指定文件夹下所有docx格式学生实验报告，提取报告内考试分数，结合自定义实验提示词，调用**DeepSeek API**自动生成教师评语，并直接写入Word文档评语栏，实现老师批量改作业、自动生成评语的实际办公落地用途。

## 二、整体任务要求
1. 读取指定文件夹下所有实验报告，仅处理 **docx** 格式，不支持doc格式
2. Qt界面配置DeepSeek接口地址、API Key
3. 支持输入每次实验对应的自定义提示词
4. 一键调用AI生成评语，自动回写插入Word文档末尾评语栏
5. 界面展示运行日志，提示文件写入状态

## 三、界面布局组成
- DeepSeek URL 输入框
- API Key 单行输入框
- 文件夹路径显示框 + 文件夹选择按钮
- 本次实验提示词：多行大文本输入框
- 确定按钮、重置按钮
- 日志显示区域（展示成功写入文件、异常信息等）

## 四、核心技术技能点
### 1. Qt 桌面开发
- QWidget 主窗口搭建
- QLineEdit 单行输入框、QTextEdit 多行文本框
- QPushButton 按钮、QLabel 标签控件使用
- QFileDialog 实现**选择文件夹**功能
- 布局管理：网格布局、垂直/水平布局排版
- Qt 信号与槽机制，绑定按钮点击事件
- 重置功能：清空所有输入框、清空日志

### 2. 文件批量处理
- 遍历指定文件夹，筛选后缀为 `.docx` 文件
- 批量读取文件列表，逐个处理

### 3. Word 文档操作
- 解析docx实验报告，提取**成绩分数**
- 定位文档教师评语位置
- 将AI生成的评语写入Word指定位置
- 保留原文档格式，只新增/修改评语内容

### 4. DeepSeek API 对接
- Qt Network 网络模块发起HTTP请求
- 配置DeepSeek官方接口地址
- 携带API Key、实验分数、自定义提示词发起请求
- 解析后端JSON返回数据，提取AI评语文本

### 5. 业务逻辑与日志
- 循环批量处理每一份实验报告
- 网络异常、空路径、无docx文件、APIKey错误容错处理
- 日志实时打印：成功写入xx文件、错误提示等

## 五、开发步骤
1. 新建Qt Widget项目，完成所有界面控件布局
2. 实现文件夹选择功能，获取路径并遍历docx文件
3. 封装DeepSeek API网络请求函数
4. 开发docx文档解析：读取分数、定位评语位置
5. 组装提示词+分数参数，调用大模型接口
6. 获取AI返回评语，写入对应Word文档
7. 完成重置按钮、日志输出、异常捕获
8. 整体联调测试批量生成、接口稳定性

## 六、应用场景
高校任课教师批量批改学生实验报告，根据实验成绩+实验要求，AI自动生成专业教师评语，大幅减少手动写评语工作量。
