# Vibe Snake — 项目规格说明书

## 1. 项目概述

**项目名称**：Vibe Snake

**目标**：使用纯 C 语言 + raylib C API 实现一个单机版贪吃蛇 PC 客户端小游戏，以双向循环链表作为蛇的核心数据结构，在游戏中学习链表的实际应用场景。

**技术栈**：
- 语言：纯 C（C99/C11）
- 界面库：raylib 5.5.0（C API，`raylib.h`）
- 测试框架：Google Test（Visual Studio 内置适配器）
- IDE：Visual Studio 2022（v143 平台工具集）
- 构建：MSBuild + NuGet（已有 raylib 包引用）

**说明：**
- 游戏逻辑层**完全不依赖 raylib**，纯 C 标准库，可用 gtest 直接测试
- UI 层通过 raylib C API 渲染，调用游戏逻辑层获取状态
- 主循环中：`处理输入 → 更新游戏逻辑 → 渲染`

### 3.3 双向循环链表设计

```c
// 链表节点
typedef struct ListNode {
    int x, y;              // 坐标数据（用于蛇身格子）
    struct ListNode *prev;
    struct ListNode *next;
} ListNode;

// 链表头（哨兵节点）
typedef struct {
    ListNode *sentinel;    // 哨兵节点，不存数据
    int size;              // 节点数量（不含哨兵）
} List;
```

**哨兵模式**：`sentinel->next` 指向第一个节点，`sentinel->prev` 指向最后一个节点，形成双向循环。

**蛇的表示**：蛇的每一节是一个 `ListNode`，蛇的整体 = 一个 `List` 实例。

**核心操作**：
- `push_front`：蛇头前进（插入新头）
- `pop_back`：未吃到食物时，移除蛇尾
- `push_back`：吃到食物时，蛇尾增长
- `get_head` / `get_tail`：获取首尾节点

## 7. VS 工程配置注意事项

- 源代码使用 `.c` 扩展名，Visual Studio 自动按 C 编译
- 现有 `.vcxproj` 中 `LanguageStandard` 设为 `stdcpp20`，仅影响 `.cpp` 文件（测试代码）
- `.c` 文件不受 C++ 标准影响，编译为 C99/C11
- 需在 `.vcxproj` 中添加所有 `.c` 源文件到 `<ClCompile>` / `<ClInclude>` 项
- 测试项目建议新建一个 Google Test 项目（.vcxproj）添加到同一解决方案
